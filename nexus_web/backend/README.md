# Nexus Web Backend

- FastAPI tabanlı REST API
- Davet kodu ile kayıt, ücretli/ücretsiz üyelik, JWT ile kimlik doğrulama (geliştirilebilir)
- Frontend ile tam entegre

## Başlangıç

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

## Özellikler
- Kayıt, giriş, kullanıcı bilgisi
- CORS desteği (localhost:3000 için)
